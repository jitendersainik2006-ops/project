FAQ

Project explanation points

Is this a MERN project?

Yes. It follows MERN-style architecture with a Node API and frontend client. MongoDB can be connected later by replacing the JSON file functions with database models.

Can it be used for clinics and coaching centers?

Yes. Services, lead sources, stages, and appointment fields are generic and can be customized for both use cases.

Does it include validation?

Yes. The appointment form validates required fields and a 10 digit phone number before sending data to the backend.
