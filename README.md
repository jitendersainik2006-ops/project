# Smart Appointment & Lead Management

MERN-style capstone project based on the ATITECH brief image. It includes appointment booking, lead tracking, customer management, analytics, reminders, notice board, FAQ, and contact capture.

## Run

```bash
npm start
```

Open:

```text
http://localhost:4500
```

## API

- `GET /api/stats`
- `GET /api/appointments`
- `POST /api/appointments`
- `GET /api/leads`
- `POST /api/leads`
- `POST /api/contact`

This project uses Node.js with local JSON storage so it runs immediately without MongoDB setup. You can later replace `data/db.json` with MongoDB models.
